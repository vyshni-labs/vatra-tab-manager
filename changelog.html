Changelog

What changed in each version, newest first.

vatra on the Chrome Web Store

0.4.3 — August 2026

  • Your hottest tabs stay hottest after a restart. Heat and last-used times were being handed to whichever tab happened to reopen in the same slot, so the order came back quietly wrong every time you restarted the browser.
  • The panel stops opening when you only sweep past it. Moving the pointer quickly toward the edge — heading for the scrollbar, or just crossing the screen — could open it on the way past. It now opens only if the pointer is still there when it arrives.
  • Closed lists tabs you actually closed. It was showing recently visited pages that simply weren't open, which is not the same thing.
  • Reopening a window full of tabs is lighter. Restoring a session saved and redrew once per tab; now it does both once for the whole batch.

0.4.2 — August 2026

  • Clearer name and description on the Chrome Web Store.

0.4.1 — August 2026

  • Better search results. The closest match comes first now, instead of whichever matching tab happened to be hottest.
  • Several words, any order. auth jira and jira auth both find the same tab, and each extra word narrows the list. Typos still land: athn finds Authentication.
  • Search is no longer reshuffled by the current view, sort or time filter while you type — they dim and step aside until the box is empty. This also fixes an open tab going missing from its own search when a narrow time filter was set.
  • The panel's controls stay readable over busy pages. The header is now held more opaque than the list below it.
  • Faster typing in the search box with hundreds of tabs open.
  • Rate us link in Settings, now that vatra is on the store.
  • Fixed: the buttons down the left strip weren't quite aligned with each other.

0.4.0 — August 2026

First public release.

  • The open-hearth mark and one warm scale — gold through grey — carrying every heat and age signal in the panel.
  • Closed view. Recently closed pages, one click to rekindle.
  • Alt+S opens the panel with the search box focused, from anywhere.
  • Chrome's native side panel as an alternative. The overlay can't appear on chrome:// pages, the Web Store, the PDF viewer or a blank new tab; there, vatra opens in the browser's own sidebar. Choosable outright in Settings → Panel type.
  • Site icons come from Chrome's local cache, so browsing the panel contacts nothing.
  • Fixed: the panel disappearing on some web apps, ghosting behind it while scrolling, and the keyboard shortcut going dead in a window until restart.

Versions before 0.4.0 were development builds and were never released.
